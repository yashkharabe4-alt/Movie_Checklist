# Movie Watch List Dashboard

A simple standalone HTML dashboard for a linked-list based C++ Movie Watch List mini project.

## Run it

Open `index.html` in any modern web browser.

## Features

- Add movies with title, year, genre, and status.
- Mark a movie watched or unwatched.
- Delete movies.
- Search and filter the current list.
- View total, to-watch, watched, and completion statistics.

Movie data is saved in the browser's local storage. This is a front-end visual companion to the C++ project; it does not call the C++ linked-list code.
